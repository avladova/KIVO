# KIVO v4 — functional demo

## Что исправлено
- Работает навигация левого меню: Потенциал подразделения / Проектные запросы / Цифровые профили / Компетенции КРМ / Команды / «Белые пятна».
- Есть форма создания проектного запроса: название, ответственный, описание, требования КРМ с уровнями.
- Есть форма добавления цифрового профиля и импорт подробного JSON.
- Есть просмотр фрагмента онтологии КРМ.
- Есть отдельный экран «Белые пятна» с Gap и способом закрытия дефицита.
- Данные, введённые в демо, сохраняются в localStorage браузера.

## Как вводятся данные
Проектный запрос: «Проектные запросы» → «+ Добавить запрос» → название + описание + `MF-1=0.9; MF-3=0.85; BD-4=0.75` → «Сохранить».

Цифровой профиль: «Цифровые профили» → ID + роль + факты цифрового следа + компетенции КРМ; либо «Импорт JSON» → выбрать JSON → проверить форму → сохранить.

Компетенции: «Компетенции КРМ» показывает справочник/онтологический фрагмент. В промышленной версии редактирование КРМ должно быть отдельным администрируемым контуром с версионированием.

Белые пятна: «Белые пятна» → проектное требование, потенциал подразделения и `Gap = требование − потенциал`; затем способ закрытия: внутренний эксперт, развитие или внешний партнёр.

Важно: это UI-демонстратор. Предзаданные 42% и Gap демонстрируют сценарий сильного дефицита; промышленный расчёт выполняется математической моделью из основной версии проекта.
