# КИВО 2026 v3 — математическая версия

Новая версия проекта с онтологией компетенций, поиском компетенций для проектной задачи и расчётом покрытия проекта.

Основной сценарий: проектная задача → требуемые компетенции → поиск экспертизы → покрытие → проектная команда → белые пятна.

Термины согласованы с презентацией КИВО: цифровой профиль сотрудника, компетенции, научные направления, индикаторы активности, роли и результаты, тематические кластеры, пересечения компетенций, потенциальные коллаборации, проектные команды, белые пятна, распределение нагрузки.

В базовой модели организационный вес сотрудника не используется: компетентность отделена от административного статуса. Доступность и нагрузка учитываются как ограничения при формировании команды.

См. `docs/MATHEMATICAL_MODEL.md`, `data/competency_ontology.json`, `data/synthetic_profiles.json`, `data/tasks.json` и `demo/index.html` внутри `v3/`.
