# Публикация KIVO v3 через GitKraken

Ветка: `kivo-v3-math-competency`.

В этой ветке уже размещены математическая модель, онтология, синтетические профили, проектные задачи, демонстратор и содержание презентации.

Презентация PowerPoint подготовлена отдельно локально: `KIVO_2026_v3_математическая_модель.pptx`.

Для публикации самого бинарного PPTX через GitKraken: checkout ветки `kivo-v3-math-competency`, скопировать PPTX в `v3/presentation/`, Commit, Push.

Для просмотра демонстратора открыть `v3/demo/index.html`.
