# Сценарий демонстрации v3

1. Выбрать проектную задачу.
2. Показать набор требуемых компетенций из онтологии.
3. Показать общий процент покрытия проекта.
4. Показать профиль подразделения по компетенциям.
5. Показать наиболее релевантных экспертов.
6. Показать белые пятна — дефициты требуемых компетенций.

Ключевая фраза: «Навигатор отвечает не на вопрос, кто работает в подразделении, а на вопрос, какие компетенции доступны организации для конкретного проекта и чего не хватает».
