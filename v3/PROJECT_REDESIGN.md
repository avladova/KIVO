# КИВО 2026 v3 — новая версия проекта

## Главный продуктовый сценарий

**проектная задача → требуемые компетенции → поиск экспертизы → расчёт покрытия → проектная команда → белые пятна и потенциальные коллаборации.**

Это развивает исходную логику проекта: цифровой профиль сотрудника, тематические кластеры, пересечения компетенций, рекомендации для проектных команд, поиск новых направлений и визуализацию белых пятен.

## Что изменилось

1. Организационный вес сотрудника исключён из базовой модели.
2. Введена онтология компетенций как связующий слой между цифровым следом и проектной задачей.
3. Добавлен явный поиск компетенций для проекта.
4. Введён показатель Coverage — покрытие проекта компетенциями.
5. Разделены Coverage, Fit и TeamFit.
6. «Белые пятна» определяются через дефициты требуемых компетенций.
7. Доступность и нагрузка сотрудника учитываются как ограничения при формировании команды, но не изменяют его профиль компетенций.

## Терминология

Используются формулировки исходной презентации: «цифровой профиль сотрудника», «компетенции», «научные направления», «индикаторы активности», «роли и результаты», «тематические кластеры», «пересечения компетенций», «потенциальные коллаборации», «проектные команды», «белые пятна», «распределение нагрузки».

## Зачем нужна онтология

Онтология связывает цифровой след, индикаторы активности, области знания, компетенции, роли, проектные задачи и результаты. Поэтому поиск работает не только по совпадению слов: связанные компетенции могут сопоставляться через иерархию и отношения «часть», «связана с», «предпосылка», «применяется в», «дополняет».

## Демонстратор

`v3/demo/index.html` показывает выбор проектной задачи, требуемые компетенции, покрытие проекта, профиль подразделения, наиболее релевантных экспертов и белые пятна.
