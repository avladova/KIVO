# KIVO v4 — Сервис оценки компетенций в научно-образовательные проекты

v4 перестраивает проект вокруг проверяемой цепочки: **цифровой след → цифровой профиль сотрудника → компетенции КРМ → профиль подразделения → требования проекта → покрытие → «белые пятна» → проектная команда/коллаборация**.

Что добавлено:
- прозрачное объяснение происхождения JSON;
- архитектура хранения raw-профилей и механизм update;
- три представления дефицита компетенций;
- фрагмент онтологии из КРМ ИТМО;
- синтетические цифровые профили;
- более функциональный HTML-демонстратор;
- обновлённая PDF-презентация.

Raw-профили не публикуются в GitHub. В репозитории только синтетические/обезличенные данные.

Основные файлы:
`docs/MATHEMATICAL_MODEL.md`
`docs/DATA_ARCHITECTURE.md`
`data/competency_ontology.json`
`data/profile_example_from_trace.json`
`data/synthetic_profiles.json`
`data/tasks.json`
`demo/index.html`
`presentation/KIVO_2026_v4_сервис_оценки_компетенций.pdf`
