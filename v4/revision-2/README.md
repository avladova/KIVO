# КИВО v4 — Сервис оценки компетенций в научно-образовательные проекты

v4 развивает проект из новой презентации и делает происхождение цифровых профилей и дефицитов проверяемыми.

## Основные изменения
1. Подробный JSON хранит не только итоговые компетенции, но и образование, ДПО, преподавание, исследования и evidence.
2. Явно зафиксировано: демонстрационный JSON вручную структурирован по предоставленному TXT и не является автоматическим парсером.
3. Описан промышленный конвейер: extraction → normalization → KRM mapping → evidence → aggregation.
4. Добавлена процедура апдейта JSON: новые evidence, инкрементальный пересчёт, `profile_version`, `mapping_version`, change log.
5. Добавлен проектный запрос с выраженным дефицитом компетенций: покрытие 42%.
6. Добавлены матрица дефицитов и карта «белых пятен».
7. Добавлен фрагмент КРМ ИТМО.

## Файлы
`data/profile_example_detailed.json` — подробный цифровой профиль.
`data/krm_ontology_fragment.json` — фрагмент КРМ.
`data/project_strong_gap.json` — проект с выраженным дефицитом.
`docs/PROFILE_UPDATE_PROCEDURE.md` — получение и обновление профилей.
`docs/MATHEMATICAL_MODEL.md` — математическая модель.
`demo/index.html` — локальный интерактивный демонстратор.
`presentation/KIVO_v4.pdf` — презентация.

Raw персональные данные хранятся во внутреннем защищённом контуре; GitHub содержит только синтетические/обезличенные данные.
