# Математическая модель v4

Сервис оценивает соответствие цифровых профилей сотрудников и подразделения требованиям конкретного научно-образовательного проекта.

Для свидетельства активности s сотрудника i:
`w_is = norm(x_is) × q_s × d_is`.

Для компетенции k:
`C_ik = Σ_s w_is × a_isk`,
где `a_isk` — степень соответствия evidence дескриптору компетенции КРМ.

Нормированный профиль:
`p_ik = C_ik / max_k(C_ik)`.

Профиль подразделения:
`P_Dk = 1 − Π_i(1 − p_ik)`.

Требования проекта задаются вектором `g_t`.
`Coverage_Dk(t) = min(P_Dk/g_tk,1)`.
`Coverage(D,t) = Σ_k g_tk Coverage_Dk(t) / Σ_k g_tk`.
`Gap_Dk(t) = max(g_tk − P_Dk,0)`.

Для команды A:
`P_Ak = 1 − Π_i∈A(1 − p_ik)`.

Косинусное сходство используется как дополнительная мера релевантности профиля проекту; основной управленческий показатель — покрытие проекта.

Нагрузка не является множителем компетенции:
`load_i + project_load_i ≤ capacity_i`.
