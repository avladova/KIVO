# Сценарий демонстрации

1. Открыть `demo/index.html`.
2. Выбрать задачу: ИИ в образовании, финтех-аналитика или цифровая образовательная платформа.
3. Нажать «Построить навигацию».
4. Показать карту компетенций — это визуальный слой организационного потенциала.
5. Показать рекомендованную тройку — система связывает задачу с профилями.
6. Кликнуть по сотруднику — открыть синтетический цифровой профиль.
7. Объяснить логику: совпадение компетенций + тематик + активность.
8. Завершить цепочкой: **данные → профиль → карта → рекомендация → команда → результат**.

Для презентации рекомендуется проговаривать, что текущая версия — демонстратор, а промышленный продукт потребует подключения реальных источников, согласования модели компетенций и валидации рекомендаций пользователями.
