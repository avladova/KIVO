# Источники и происхождение материалов

Основные материалы проекта: исходный пример цифрового следа; презентации проекта КИВО 2026; фрагмент КРМ, использованный для построения единого словаря компетенций.

`data/profile_example_detailed.json` — обезличенная демонстрационная структура, вручную сформированная по цифровому следу. Это не автоматический парсинг TXT.

`data/competency_ontology.json` — канонический словарь компетенций КРМ, используемый демонстратором.

Raw-цифровой след и необезличенные персональные данные не входят в публичную структуру репозитория.
