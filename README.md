# Сервис оценки компетенций научно-образовательных проектов

Репозиторий содержит конечный функциональный демонстратор сервиса оценки покрытия компетенций проектного запроса цифровыми профилями сотрудников подразделения, выявление «белых пятен» и подбор команды.

## Демонстрация

- **Потенциал подразделения** — покрытие требований проекта.
- **Проектные запросы** — ввод названия, описания и требований к компетенциям КРМ.
- **Цифровые профили** — ввод профиля и импорт JSON.
- **Компетенции КРМ** — фрагмент онтологии «цифровой след → индикатор активности → компетенция → роль → проектная задача → результат».
- **Команды** — пример формирования команды по дефицитным компетенциям.
- **«Белые пятна»** — требование проекта, потенциал подразделения, Gap и способ закрытия дефицита.

## Запуск

Откройте [`demo/index.html`](demo/index.html) локально в браузере. Сервер для демонстрации не требуется.

Все данные демонстратора обезличенные. В промышленной версии raw-цифровой след хранится во внутреннем защищённом контуре, а JSON является актуализируемой аналитической витриной профиля.

## Материалы v4

- `v4/revision-2/data/` — подробный цифровой профиль, фрагмент КРМ и проект с выраженным дефицитом.
- `v4/revision-2/docs/` — математическая модель и процедура получения/обновления цифровых профилей.
- `v4/` — материалы предыдущей итерации R&D-проработки.

## Ограничение демонстратора

Текущий интерфейс демонстрирует пользовательский сценарий и структуру данных. Полный промышленный расчёт покрытия выполняется математической моделью на основе цифрового следа и сопоставления с КРМ.
