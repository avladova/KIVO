# Сервис оценки компетенций в научно-образовательные проекты

Конечный демонстратор КИВО v4. Сервис связывает цифровые следы сотрудников с компетенциями КРМ, требованиями проектного запроса и формированием команды.

## Что находится в корне

- `demo/index.html` — единственный канонический интерактивный демонстратор.
- `data/competency_ontology.json` — единый словарь компетенций КРМ, используемый интерфейсом проектных запросов и профилей.
- `data/profiles.json` — синтетические профили, выраженные через КРМ.
- `data/project_strong_gap.json` — демонстрационный проектный запрос.
- `docs/PROJECT.md` — описание продукта, проблемы, ценности и пилота.
- `docs/MATHEMATICAL_MODEL.md` — математическая модель покрытия и дефицитов.
- `docs/PROFILE_UPDATE_PROCEDURE.md` — получение, обновление и защита цифровых профилей.
- `docs/DEMO.md` — сценарий демонстрации.
- `v4/` — архив значимых материалов R&D предыдущих итераций; не используется как источник данных демонстратора.

## Логика демонстратора

`цифровой след → evidence → компетенция КРМ → цифровой профиль → проектный запрос → покрытие → «белые пятна» → команда`

### Проектный запрос

В разделе «Проектные запросы» пользователь задаёт название и описание задачи, затем выбирает требуемые компетенции **из списка КРМ** и задаёт целевой уровень. Свободного ввода идентификаторов компетенций нет.

### Цифровой профиль

Профиль вводится вручную или импортируется JSON. В промышленной версии источниками будут ETL/API информационных систем организации. Raw-данные и персональные данные хранятся во внутреннем защищённом контуре.

### Покрытие компетенций

Сервис рассчитывает совокупное покрытие подразделения по требованиям проекта и показывает по каждой компетенции: требуется, есть, дефицит.

### «Белые пятна»

Раздел показывает компетенции, где `Gap = max(требование − потенциал, 0)`, и предлагает способ закрытия: внутренний эксперт, развитие или внешний партнёр.

## Конфиденциальность

В публичной части репозитория используются только синтетические или обезличенные данные. Необезличенный демонстрационный файл из старой ревизии исключён из рабочей структуры `main`.

## Запуск

Откройте `demo/index.html` локально в браузере. Сервер и Python не требуются.
