# КИВО 2026 — Цифровой навигатор потенциала образовательных организаций

Репозиторий содержит автономный демонстратор проекта для заявки КИВО 2026.

## Что демонстрируется

Демонстратор показывает цепочку:

**данные → цифровые профили → карта компетенций → рекомендация → проектная команда.**

Можно выбрать проектную задачу, увидеть распределение компетенций и получить ранжированный список из трёх наиболее релевантных сотрудников. Профиль каждого сотрудника открывается кликом.

Все персоналии, показатели и связи в демо являются **синтетическими**.

## Структура

- `demo/index.html` — автономный работающий демонстратор.
- `data/profiles.json` — синтетические цифровые профили.
- `data/tasks.json` — сценарии проектных задач.
- `docs/PROJECT.md` — описание проекта и логики пилота.
- `docs/DEMO.md` — сценарий показа.
- `GITKRAKEN.md` — инструкция публикации через GitKraken.
- `.gitignore` — служебные исключения Git.

## Запуск

Скачайте репозиторий и дважды щёлкните `demo/index.html`. Сервер не нужен.

Для GitHub Pages файл можно будет открыть после публикации как веб-страницу.

## Важно

Это демонстратор продуктовой гипотезы, а не готовая промышленная система. В реальной версии данные подключаются из информационных систем организации, а алгоритмы рекомендаций проходят экспертную и пользовательскую валидацию.
