# Публикация проекта через GitKraken

## Вариант для репозитория KIVO

Целевой репозиторий:
https://github.com/avladova/KIVO

### 1. Скачать и распаковать

Распакуйте архив так, чтобы на компьютере появилась папка:

`KIVO-2026-Navigator`

Внутри должны находиться `README.md`, `demo`, `data`, `docs` и `.gitignore`.

### 2. Открыть папку в GitKraken

В GitKraken выберите открытие/добавление существующего локального репозитория.

Если GitKraken сообщает, что папка ещё не является Git-репозиторием, используйте создание/инициализацию репозитория в этой папке.

### 3. Подключить GitHub

Если репозиторий KIVO уже подключён в GitKraken, этот шаг пропустите.

Иначе добавьте remote:

`origin` → `https://github.com/avladova/KIVO.git`

### 4. Создать отдельную ветку

Рекомендуемая ветка:

`kivo-2026-navigator`

Это позволит сначала проверить демонстратор, не изменяя основную ветку.

### 5. Сделать commit

В GitKraken добавьте все новые файлы в staging.

Сообщение commit:

`Add KIVO 2026 digital navigator demonstrator`

Нажмите Commit.

### 6. Отправить на GitHub

Нажмите Push и отправьте ветку:

`kivo-2026-navigator`

в `origin`.

### 7. Проверить результат

Откройте GitHub и убедитесь, что появились:

- `demo/index.html`
- `data/profiles.json`
- `data/tasks.json`
- `docs/PROJECT.md`
- `docs/DEMO.md`
- `README.md`

### 8. Важный момент для демонстрации

Для локального показа достаточно открыть:

`demo/index.html`

двойным щелчком. Сервер и Python не требуются.

После проверки можно сделать Pull Request из `kivo-2026-navigator` в `main`.

## Если KIVO уже открыт в GitKraken

Не создавайте новый GitHub-репозиторий. Добавьте файлы этого проекта в локальную копию уже подключённого `KIVO`, затем создайте отдельную ветку и сделайте commit/push.
